System Design

Three-Tier Architecture

🧠

AI Detection

Captures live packets via Scapy, computes twelve statistical features per ten-second rolling window, and runs a hybrid Random Forest plus rule classifier to identify attack patterns in real time.

detector.py
🛡

Firewall Agent

Consumes JSON detection events, applies iptables DROP rules at the kernel level, and presents a tabbed dashboard with auto and manual blocking modes and auto-expiring blocks.

agent/
☁

Cloud Intelligence

Publishes threat events and block decisions to Firebase Realtime Database in real time and pulls peer-shared blocklists so every node benefits from what any node detects.

cloud_hooks.py
